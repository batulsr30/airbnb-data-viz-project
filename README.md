# Berlin vs London Airbnb Data Analysis 📊

A comparative data visualization project analyzing Airbnb listing patterns, pricing dynamics, and room-type distributions across Berlin and London.

## 📁 Repository Structure
* `DV_Final_Project.ipynb`: Executed Jupyter Notebook with Python code, data cleaning, and visualizations.
* `DV_Final_Project.html`: Standalone interactive dashboard export featuring Plotly charts.
* `listings_Berlin.csv` & `listings_London.csv`: Primary datasets used for cross-city comparison.
* `app.py`: Streamlit/Web dashboard script.
* `requirements.txt`: Python dependencies.

## 🛠️ Tech Stack
* Python (Pandas, NumPy)
* Plotly Express & Graph Objects
* HTML / CSS
